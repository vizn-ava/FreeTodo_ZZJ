# 语音转写模块接入指南（按住说 → 松开转写成文本）

本指南把“类似 typelessa 的语音输入”拆成**可复制的最小闭环**：前端录音（按住说/松开停）→ 上传音频 → 后端 ASR 转写 → 返回文本 → 回填到输入框。

参考实现来自本仓库（FreeTodo / LifeTrace）现有代码：
- 前端：`free-todo-frontend/lib/hooks/useVoiceInput.ts`
- 后端：`lifetrace/routers/audio.py`、`lifetrace/services/audio_transcription_service.py`、`lifetrace/util/path_utils.py`

> 你可以把本文档当作“在另一个工程里落地这个功能的实施说明 + 代码骨架”。

---

## 目标与范围

本模块提供两种接入模式（建议至少实现 **A**）：

- **A. 快速转写（推荐，最像 typelessa）**  
  前端录一段音频，上传到 `/api/audio/transcriptions/quick`，后端立刻返回文本；音频文件仅作临时文件，转完删除，**不落库**。

- **B. 持久化转写（可选）**  
  上传到 `/api/audio/transcriptions?process=true`，后端把音频落盘并写入 DB（`audio_records` + `audio_segments`），适合“录音日记/会议记录”这类场景。

本文重点写 **A**；最后会附上 **B** 需要补的点。

---

## 端到端流程（A：快速转写）

1. **用户按住快捷键**（或点击麦克风按钮）→ `getUserMedia({audio:true})` 获取麦克风流
2. **MediaRecorder 开始录音**，每 250ms 产出一段 chunk
3. **用户松开快捷键**（或再次点击）→ `MediaRecorder.stop()`  
   前端把 chunks 合并成 `Blob`（WebM/Ogg，Opus 编码）
4. 前端用 `FormData` 上传：`POST /api/audio/transcriptions/quick`（字段名 `file`）
5. 后端保存临时文件 → 调用 ASR（百炼 DashScope）→ 返回 `segments[]`
6. 前端把 segments 拼成最终文本 → 追加到输入框内容

## 前端接入（React/Next.js 为例）

### 1) 浏览器能力与录音格式选择

核心 API：
- `navigator.mediaDevices.getUserMedia({ audio: true })`
- `MediaRecorder`

推荐 MIME（优先顺序）：
- `audio/webm;codecs=opus`
- `audio/webm`
- `audio/ogg;codecs=opus`
- `audio/ogg`

在代码里通过 `MediaRecorder.isTypeSupported()` 挑一个当前浏览器支持的格式。

### 2) Hook：useVoiceInput（最小可用版本）

下面代码是“可抄到你工程”的精简版（接口和行为与本仓库一致）：

```ts
import type { RefObject } from "react";
import { useCallback, useEffect, useMemo, useRef, useState } from "react";

type VoiceInputError = "unsupported" | "permission" | "upload" | "empty";

const SUPPORTED_MIME_TYPES = [
  "audio/webm;codecs=opus",
  "audio/webm",
  "audio/ogg;codecs=opus",
  "audio/ogg",
];

function pickSupportedMimeType() {
  if (typeof MediaRecorder === "undefined") return undefined;
  return SUPPORTED_MIME_TYPES.find((t) => MediaRecorder.isTypeSupported(t));
}

type UseVoiceInputOptions = {
  onText: (text: string) => void;
  targetRef: RefObject<HTMLElement | null>;
  endpoint?: string;      // 默认 /api/audio/transcriptions/quick
  language?: string;      // 例如 "zh" | "en"；不传表示自动
  hotkeyCode?: string;    // 例如 "AltRight"
  onStatusChange?: (s: "recording" | "transcribing" | null) => void;
};

export function useVoiceInput({
  onText,
  targetRef,
  endpoint = "/api/audio/transcriptions/quick",
  language,
  hotkeyCode = "AltRight",
  onStatusChange,
}: UseVoiceInputOptions) {
  const [isRecording, setIsRecording] = useState(false);
  const [isTranscribing, setIsTranscribing] = useState(false);
  const [error, setError] = useState<VoiceInputError | null>(null);

  const mediaRecorderRef = useRef<MediaRecorder | null>(null);
  const streamRef = useRef<MediaStream | null>(null);
  const chunksRef = useRef<Blob[]>([]);
  const mimeType = useMemo(() => pickSupportedMimeType(), []);

  const stopStreamTracks = useCallback(() => {
    if (!streamRef.current) return;
    for (const track of streamRef.current.getTracks()) track.stop();
    streamRef.current = null;
  }, []);

  const uploadBlob = useCallback(
    async (blob: Blob) => {
      setIsTranscribing(true);
      onStatusChange?.("transcribing");
      setError(null);
      try {
        const formData = new FormData();
        const ext = blob.type.includes("ogg") ? "ogg" : "webm";
        const file = new File([blob], `voice.${ext}`, { type: blob.type });
        formData.append("file", file);

        const url = language
          ? `${endpoint}?language=${encodeURIComponent(language)}`
          : endpoint;

        const resp = await fetch(url, { method: "POST", body: formData });
        if (!resp.ok) throw new Error(`HTTP ${resp.status}`);
        const data = await resp.json();

        const segments = (data?.segments ?? []) as Array<{ text_content?: string; textContent?: string }>;
        const text = segments
          .map((s) => s.textContent ?? s.text_content ?? "")
          .filter(Boolean)
          .join(" ")
          .trim();

        if (!text) {
          setError("empty");
          return;
        }
        onText(text);
      } catch (e) {
        console.error(e);
        setError("upload");
      } finally {
        setIsTranscribing(false);
        onStatusChange?.(null);
      }
    },
    [endpoint, language, onStatusChange, onText],
  );

  const startRecording = useCallback(async () => {
    if (!navigator.mediaDevices?.getUserMedia) {
      setError("unsupported");
      return;
    }
    if (isTranscribing) return;

    try {
      const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      streamRef.current = stream;
      chunksRef.current = [];

      const recorder = new MediaRecorder(stream, mimeType ? { mimeType } : undefined);
      mediaRecorderRef.current = recorder;

      recorder.ondataavailable = (ev) => {
        if (ev.data.size > 0) chunksRef.current.push(ev.data);
      };

      recorder.onstop = () => {
        stopStreamTracks();
        const blob = new Blob(chunksRef.current, { type: recorder.mimeType || "audio/webm" });
        chunksRef.current = [];
        mediaRecorderRef.current = null;

        if (blob.size === 0) {
          setError("empty");
          setIsRecording(false);
          onStatusChange?.(null);
          return;
        }
        void uploadBlob(blob);
      };

      recorder.start(250);
      setIsRecording(true);
      onStatusChange?.("recording");
    } catch (e) {
      console.error(e);
      setError("permission");
      stopStreamTracks();
      mediaRecorderRef.current = null;
    }
  }, [isTranscribing, mimeType, onStatusChange, stopStreamTracks, uploadBlob]);

  const stopRecording = useCallback(() => {
    const recorder = mediaRecorderRef.current;
    if (!recorder) return;
    setIsRecording(false);
    onStatusChange?.(null);
    try {
      recorder.requestData();
    } catch {}
    if (recorder.state !== "inactive") recorder.stop();
    else {
      stopStreamTracks();
      mediaRecorderRef.current = null;
    }
  }, [onStatusChange, stopStreamTracks]);

  const toggleRecording = useCallback(() => {
    if (isRecording) stopRecording();
    else void startRecording();
  }, [isRecording, startRecording, stopRecording]);

  // 按住说：keydown 开始；keyup 停止（仅当 targetRef 当前聚焦）
  useEffect(() => {
    const onDown = (ev: KeyboardEvent) => {
      if (ev.code !== hotkeyCode) return;
      if (ev.repeat) return;
      if (!targetRef.current) return;
      if (document.activeElement !== targetRef.current) return;
      ev.preventDefault();
      void startRecording();
    };
    const onUp = (ev: KeyboardEvent) => {
      if (ev.code !== hotkeyCode) return;
      if (!targetRef.current) return;
      if (document.activeElement !== targetRef.current) return;
      ev.preventDefault();
      stopRecording();
    };
    window.addEventListener("keydown", onDown);
    window.addEventListener("keyup", onUp);
    return () => {
      window.removeEventListener("keydown", onDown);
      window.removeEventListener("keyup", onUp);
    };
  }, [hotkeyCode, startRecording, stopRecording, targetRef]);

  return {
    isRecording,
    isTranscribing,
    error,
    startRecording,
    stopRecording,
    toggleRecording,
    clearError: () => setError(null),
  };
}
```

### 3) UI 接入方式（输入框）

典型做法：
- 输入框是 `textarea`，传 `ref` 给 `useVoiceInput({ targetRef: textareaRef })`
- `onText(text)` 把转写结果追加到 `textarea` 当前内容

你可以同时提供：
- **麦克风按钮**：点击切换录音（移动端更可用）
- **快捷键提示**：鼠标 hover 时显示“按住 XXX 说话”

## 后端接入（FastAPI 为例）

### 1) API：快速转写（不落库）

接口约定：
- `POST /api/audio/transcriptions/quick`
- `Content-Type: multipart/form-data`
- 表单字段：`file`（音频文件）
- 可选 query：`language=zh|en|...`、`diarization=true|false`
- 返回：
  - `segments: [{ start_time, end_time, text_content, speaker?, confidence? }]`

最小骨架（可直接改成你工程的路由）：

```py
from fastapi import APIRouter, File, UploadFile, HTTPException, Query
import os, shutil
from pathlib import Path
from datetime import datetime

router = APIRouter(prefix="/api/audio", tags=["audio"])

def ensure_dir(p: str):
    Path(p).mkdir(parents=True, exist_ok=True)

def save_upload_to_tmp(upload: UploadFile, tmp_dir: str) -> str:
    ensure_dir(tmp_dir)
    ext = Path(upload.filename or "").suffix or ".wav"
    ts = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
    file_path = str(Path(tmp_dir) / f"audio_{ts}{ext}")
    with open(file_path, "wb") as f:
        shutil.copyfileobj(upload.file, f)
    return file_path

@router.post("/transcriptions/quick")
async def quick_transcription(
    file: UploadFile = File(...),
    language: str | None = Query(None),
    diarization: bool | None = Query(None),
):
    if not file.filename:
        raise HTTPException(status_code=400, detail="missing filename")

    try:
        path = save_upload_to_tmp(file, tmp_dir="./data/audio_tmp")
    finally:
        await file.close()

    try:
        # 这里调用你的 ASR service
        result = transcribe(path, language=language, diarization_enabled=bool(diarization))
        return {"status": "done", "language": result.get("language"), "segments": result.get("segments", [])}
    finally:
        try:
            if os.path.exists(path):
                os.remove(path)
        except OSError:
            pass
```

### 2) ASR 服务：百炼 DashScope（本仓库同款）

本仓库使用的是 DashScope SDK 的 ASR：
- SDK：`dashscope`
- 识别类：`dashscope.audio.asr.Recognition`

并且做了两件很关键的工程化处理：
- **WebM/Ogg 兼容**：优先用 `PyAV` 把容器转成 16k 单声道 WAV；失败则退化为“直接把 WebM/Ogg 原文件交给 ASR”（某些环境下浏览器录出来的文件尾部可能截断）
- **中文简转**：可选 `opencc` 把繁体转简体（默认启用）

你需要准备的依赖（Python）：

```txt
fastapi
uvicorn
dashscope
av            # PyAV，用于音频转码（推荐）
opencc        # 可选：繁转简
pyannote.audio  # 可选：说话人分离（diarization）
```

> 如果你不需要说话人分离，完全可以不装 `pyannote.audio`。

## 配置清单（必须项 + 可选项）

### 必须：百炼/ DashScope API Key

后端要能拿到 Key。参考本仓库的优先级：
1. 环境变量：`DASHSCOPE_API_KEY` 或 `BAILIAN_API_KEY`
2. 配置文件：`bailian.api_key`
3. 如果你复用统一 LLM 配置且 base_url 指向 dashscope，也可以用 `llm.api_key`

### 建议：workspace（可选，但推荐）

如果你在百炼控制台使用 workspace，建议配置：
- 环境变量：`DASHSCOPE_WORKSPACE` 或 `BAILIAN_WORKSPACE_ID`
- 或配置文件：`audio_transcription.bailian.workspace_id`

### 可选：语言提示

前端 `language` 建议允许：
- `"zh"` / `"en"`：明确提示
- `"auto"`：不传 language（让后端/模型自动识别）

### 可选：Diarization（说话人分离）

本仓库在服务端支持 `diarization_enabled`，需要：
- `audio_transcription.diarization.enabled=true`
- `audio_transcription.diarization.model=...`
- 若模型需要 HuggingFace token：`audio_transcription.diarization.auth_token=...`

## 运行与联调（Checklist）

### 前端
- 浏览器是否支持 `MediaRecorder`（Chrome/Edge 通常 OK）
- HTTPS/localhost 才能稳定拿到麦克风权限
- `endpoint` 是否与后端路由一致（例如 `/api/audio/transcriptions/quick`）

### 后端
- `DASHSCOPE_API_KEY` 是否已设置且有效
- 上传体积限制（FastAPI/反向代理）是否允许音频文件
- 如使用 PyAV：运行环境是否有相应解码能力（PyAV 通常自带/依赖 FFmpeg）

## 常见问题与排错

- **录音没反应 / 报 unsupported**  
  说明浏览器不支持 `MediaRecorder` 或 `getUserMedia`。需要降级方案（例如 WebAudio + WAV 编码）或提示换浏览器。

- **permission denied**  
  用户拒绝麦克风权限；检查站点权限、HTTPS、系统麦克风设置。

- **后端 500：Bailian API key is missing**  
  Key 没配置。优先用环境变量注入，避免写死在代码里。

- **转写结果为空**  
  可能录音时长太短/静音；前端应把 `blob.size === 0` 当作 empty；后端可对极短音频返回更友好错误。

## 可选：持久化模式（B）要做什么？

如果你希望“音频+转写结果”可在后台查看（类似本仓库 `DiaryPanel`），需要：

1. 后端新增（或保留）接口：`POST /api/audio/transcriptions?process=true`
2. 存储目录：通过配置决定 `audio_dir`（默认 `data/audio/`）
3. DB 表：
   - `audio_records`：文件路径、hash、size、duration、status、language...
   - `audio_segments`：每个分段的 start/end/text/speaker/confidence
4. 前端增加页面：列出 records、拉取 segments、支持重命名/删除/导入到聊天等

本仓库已实现可参考：
- 前端：`free-todo-frontend/apps/diary/DiaryPanel.tsx`
- 后端：`lifetrace/routers/audio.py`（`/transcriptions` + `/records/*`）

## 最小验收标准（你工程接入完成的判定）

- 输入框聚焦时按住快捷键开始录音，松开后 1~3 秒内文本自动回填
- 点击麦克风按钮也能完成录音/停止/回填
- 后端能稳定返回 `segments[].text_content`，前端拼接后为空则提示“未识别到内容”
- Key 未配置时返回明确错误（HTTP 400/500 均可，但要可读）
